## 产品判断

UI Agent 的失败不是一个结果标签，而是一条可被逐段理解的因果链。评测设计因此围绕“可观察”展开。

## 证据与产物

- 真实移动任务分层与成功条件
- 步骤级轨迹和关键页面快照
- 感知 / 规划 / 执行三级失败地图
- 风险动作与人工接管规则
