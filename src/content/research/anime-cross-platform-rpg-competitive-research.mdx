## 执行摘要

本研究不是“哪款游戏更好”的主观排名，而是使用统一产品框架判断：不同设计服务了哪类玩家、建立了什么核心循环、付出了什么产品代价，以及哪些业务问题值得转化为 AI 产品机会。

四款产品共享风格化 3D 角色、跨移动端与 PC 或主机发行、多角色养成、实时控制、长线版本更新和角色驱动商业化等基础，因此会竞争相似的用户时间、内容注意力与付费预算。但它们并非完全同质，差异已经从“是否拥有开放世界”转向四条更具体的路线：

- 《原神》以“世界内容 + 角色叙事”建立综合循环，优势来自内容生产、跨端可达性和长期角色资产。
- 《鸣潮》以“动作战斗 + 高机动探索”形成操作识别度，角色的操作方式本身可以成为获取理由。
- 《明日方舟：终末地》以“实时小队战斗 + 工业生产”建立系统型差异，生产结果反哺装备、地区发展与探索。
- 《异环》以“都市空间 + 生活互动”建立题材和生活幻想优势，角色价值从战斗延伸到城市陪伴、车辆与房产。

近期 AI 机会更适合研发侧，包括版本知识库、角色一致性评测、测试 Agent、玩家反馈聚类和本地化辅助。玩家侧 AI 具有更高想象空间，但需要同时满足延迟、成本、世界观一致性、安全和降级要求。

## 研究问题

报告围绕四个问题展开：

1. 四款产品分别争夺什么用户心智？
2. 战斗、世界结构、角色与长期系统如何进入核心循环？
3. 差异化能否支持持续内容供给，并与角色价值及商业化协同？
4. 基于真实业务矛盾，游戏 AI 应优先进入哪些研发和玩家体验环节？

## 研究方法与边界

研究使用中文官方资料和版本公告确认产品类型、平台、上线状态与公开机制；结合实际体验和界面观察记录核心行为、系统连接与操作成本；使用国内公开社区反馈形成问题假设；最后用统一框架比较四款产品，并从痛点反推 AI 的输入、输出、人工确认、评测与降级机制。

| 证据类型 | 含义                                 | 在网页版本中的使用方式               |
| -------- | ------------------------------------ | ------------------------------------ |
| 公开事实 | 官网、公告、开发者访谈与正式版本信息 | 可以直接描述，并在 PDF 附录列出来源  |
| 体验观察 | 作者实际游玩、系统记录和界面观察     | 标明观察时间与体验边界               |
| 玩家反馈 | 公开社区、商店评论和视频评论         | 用于形成问题假设，不等同于真实发生率 |
| 产品推断 | 基于机制、循环与用户价值形成的判断   | 使用“本报告判断”“待验证”等限定词     |

资料观察截止到 2026 年 7 月 30 日。本文不进行流水排名、公司经营预测或未公开研发流程推测，也不以画面、个人喜好或功能数量判断产品强弱。雷达图、热力图和矩阵评分均为研究性判断，不代表官方数据、真实留存率或总体用户结论。

## 品类关系与产品定位

竞品研究的价值不在于强行把产品放入同一个总分榜，而是识别哪些基础框架相似，哪些核心行为不同，以及差异化是否真正进入高频循环。

| 产品   | 主要行为价值         | 差异化来源                               | 需要继续验证的长期问题                   |
| ------ | -------------------- | ---------------------------------------- | ---------------------------------------- |
| 原神   | 世界发现与角色陪伴   | 国家式世界扩展、元素反应、角色与剧情运营 | 高质量内容供给能否持续覆盖生产成本       |
| 鸣潮   | 操作表达与战斗掌控   | 闪避、弹反、切换、高机动与声骸           | 战斗机制创新能否持续，移动端门槛是否可控 |
| 终末地 | 规划、建设与地区改造 | 工业生产、资源网络、实时小队战术         | 工业能否持续产生有意义决策，而非管理负担 |
| 异环   | 都市生活与角色关系   | 城市空间、异常事件、载具、房产与经营     | 生活模块能否形成强闭环，而非功能集合     |

### 谁会因为什么长期留下

目标用户不应该只按“二次元玩家”划分，而要看玩家希望在游戏中获得的主要价值。原神偏内容陪伴，鸣潮偏动作表达，终末地偏系统建设，异环偏都市生活。进入动机可能来自角色、美术和宣发，长期留存则取决于核心循环能否持续兑现这项承诺。

## 核心玩法与产品循环

本文把循环拆成三个层级：单局行为循环决定即时反馈，日常成长循环决定留存与疲劳，版本内容循环决定回流和角色商业化。分析重点是核心乐趣最早出现在哪一环、差异化是否进入高频行为、养成是否反哺核心玩法，以及版本更新是在扩展循环还是只增加一次性内容。

| 产品   | 核心乐趣最早出现               | 长期目标来源                       | 主要疲劳点                     | 阶段性判断                             |
| ------ | ------------------------------ | ---------------------------------- | ------------------------------ | -------------------------------------- |
| 原神   | 发现并抵达未知地点             | 角色获取、队伍构建、世界与账号积累 | 体力副本、随机养成和版本间等待 | 循环成熟，但高度依赖高质量内容供给     |
| 鸣潮   | 成功闪避、弹反和角色连携       | 角色熟练度、队伍协同和声骸优化     | 声骸筛选、重复战斗与操作负荷   | 即时循环强，长期依赖敌人与角色机制创新 |
| 终末地 | 第一条有效生产线与小队协同     | 工厂扩张、区域发展、装备和干员     | 生产维护、资源领取与多系统并行 | 系统闭环强，取决于工业产出的长期价值   |
| 异环   | 都市移动、异常反差和角色生活感 | 羁绊、车辆、房产和城市资产         | 小游戏、城市体力和多目标分散   | 入口丰富，需要强化模块间因果连接       |

内容驱动循环容易建立情感和回流高峰，但生产成本高、内容消耗快；操作驱动循环能让战斗本身形成价值，却会缩小用户覆盖并提高移动端适配难度；系统驱动循环具有重复利用与长期优化空间，但复杂系统可能转化为日常管理负担；生活驱动循环能够扩大身份表达与角色陪伴价值，但要保证各模块不只是通过货币奖励被动连接。

## 战斗、世界与角色价值

### 战斗在产品中的职责

《原神》的战斗更像角色与内容消费的连接器：低门槛保证泛用户可达，深度集中在配队和元素循环。《鸣潮》把战斗过程本身提升为核心卖点，使角色“是否好玩”与强度同样重要。《终末地》将单角色动作转化为实时小队战术，战斗同时承担工业与养成结果的验证端。《异环》需要战斗足够华丽流畅，但不宜阻挡用户进入都市与角色内容。

不同战斗设计没有统一的“最好”。高操作上限提高掌控感，但会降低跨端可达性；低操作门槛扩大用户覆盖，却需要持续通过角色、敌人和队伍机制提供新鲜感。

### 世界结构不是面积竞赛

地图规模并非核心竞争力。高密度且可记忆的空间节点，比空旷规模更能形成长期心智。高机动应该降低无价值重复，而不是消除所有空间决策；探索奖励也不只承担资源功能，场景、音乐、故事和可持续系统反馈共同决定玩家是否愿意偏离主线。

终末地和异环的关键验证点，是建设或生活系统能否真正改变玩家对空间的使用方式。如果工业建设只是额外领取流程，或城市生活只是可浏览的功能集合，差异化就没有进入主循环。

### 角色是跨系统的长期资产

角色价值不只来自战斗强度，还来自剧情身份、世界关系、非战斗互动和长期陪伴。随着角色数量、剧情文本与本地化规模扩大，最现实的 AI 问题不是让模型自由写角色，而是维护已有设定：世界观资料检索、角色人设跨版本一致性、剧情冲突、环境对白批量检查、多语言术语统一和 Bad Case 回归。

## 内容供给与版本循环

长线产品需要同时提供高峰内容和低成本常驻目标。地图、主线与角色形成版本回流高峰；日常、养成、挑战和系统优化填补内容间隔；社区、二创与旧内容复用影响版本之外的持续关注。

| 压力来源     | 业务表现                               | 可能的产品方向                           |
| ------------ | -------------------------------------- | ---------------------------------------- |
| 地图与场景   | 制作周期长、一次性消费快               | 程序化辅助、旧区域事件化、资产检索与复用 |
| 角色资产     | 模型、动作、技能、剧情、语音和营销协同 | 角色资料库、一致性评测与资产流程检查     |
| 剧情与本地化 | 文本量、术语和跨版本一致性             | 知识库、术语检查、本地化辅助与人工审核   |
| 多平台测试   | 设备、分辨率、输入和性能组合快速膨胀   | UI Agent、视觉检测、自动回归与日志归因   |
| 玩家消费速度 | 集中完成版本后进入等待期               | 常驻循环、系统复用、回流摘要与节奏设计   |

原神的内容引擎是地区、角色与剧情；鸣潮需要持续生产敌人、角色动作和操作机制；终末地可以通过配方、物流、区域与工业目标形成系统性供给；异环可以通过城市事件、房产、载具、经营和角色互动降低对纯地图扩张的依赖。差异化系统只有在能够持续生成目标与版本空间时，才构成长期壁垒。

## 玩家生命周期与长期价值

玩家生命周期不是自动推进的漏斗，而是一组连续价值验证：宣传是否准确建立期待，新手阶段是否迅速兑现核心乐趣，成长系统是否给出明确目标，内容是否支持长期投入，商业化是否与角色及体验价值匹配，版本更新是否值得回流。

| 阶段     | 核心问题                     | 主要风险                               |
| -------- | ---------------------------- | -------------------------------------- |
| 认知获客 | 卖点是否准确吸引目标用户     | 宣发突出非核心功能，进入后预期落差     |
| 新手激活 | 多快让玩家体验核心乐趣       | 信息过载、乐趣出现过晚、操作或系统门槛 |
| 早期留存 | 目标—行动—反馈是否清晰       | 资源卡点、养成复杂、重复任务过早       |
| 深度参与 | 差异化能否持续产生新目标     | 内容消耗、系统固化、挑战变化不足       |
| 稳定活跃 | 版本更新是否持续兑现期待     | 日常上班化、旧角色和旧内容失去价值     |
| 召回回流 | 能否低成本理解变化并恢复目标 | 版本积压、系统变化、账号落后和社交断裂 |

商业化也必须回到角色与体验价值：新角色是否改变玩法而非只提升数值，玩家是否在抽取前理解角色身份与长期价值，免费玩家能否完成核心内容，武器或装备是否构成过强的完整角色成本，以及旧角色是否仍有新的队伍和情感场景。

## 综合发现

综合比较后，本报告形成四个阶段性判断：原神循环最成熟，鸣潮即时反馈最集中，终末地系统连接最强，异环内容入口最丰富。长期竞争力取决于差异化能否在多个版本中持续改变玩家决策，而不是只形成首发新鲜感。

能够持续运营的差异化需要同时满足四个条件：进入核心循环、持续产生内容、与角色价值及商业化协同，并在移动端可达性和玩家时间负担之间保持平衡。系统越复杂并不代表循环越强；玩家完成一次行为后，反馈是否自然形成下一次目标，才是闭环成立的标准。

长线疲劳的本质，是玩家付出的时间与新鲜感、成长感和情感回报不匹配。降低重复不只是缩短流程，还需要增加决策变化与可见成长。

## AI 产品机会

AI 产品机会应遵循“真实痛点 → 规则系统不足 → AI 介入 → 人工确认 → 评测指标 → 风险降级”的路径。生成能力不是立项理由；只有当任务高频、成本明显、结果可验证且错误可控制时，才适合进入 MVP。

### 研发侧优先机会

| 场景           | 服务对象                | 产品价值                                      | 核心指标与降级方式                                       |
| -------------- | ----------------------- | --------------------------------------------- | -------------------------------------------------------- |
| 版本内容知识库 | 策划、编剧、运营、QA    | 统一世界观、版本规则与历史决策                | 检索命中率、引用准确率；无法确认时返回来源与不确定性     |
| 角色一致性评测 | 编剧、剧情策划、AI 团队 | 固定测试集、多轮测试与 Bad Case 回归          | 一致性、世界观准确率、越界率；高风险结论人工确认         |
| 游戏测试 Agent | QA、研发、项目管理      | 自动执行 UI、任务、跑图和回归，生成可复现报告 | 完成率、覆盖率、有效缺陷率、复现率；限定环境和动作白名单 |
| 玩家反馈聚类   | 产品、运营、客服、数据  | 识别问题主题和版本归因                        | 聚类纯度、归因准确率、分析时间；保留原文并抽样复核       |
| 本地化辅助     | 本地化、文案、法务      | 术语统一、上下文检索和初稿检查                | 术语准确率、返工率；重要剧情和文化敏感内容人工审校       |

### 玩家侧机会与边界

个性化新手引导、回流内容摘要、受控生成式 NPC、AI 队友和 UGC 创作助手都具有产品空间，但首版应该进入非核心、可退出和可回退的场景。语言模型不能直接改写主线、付费结果或实时战斗关键状态；网络或模型不可用时，产品需要退回固定内容或传统系统。

## 重点验证方案与产品启示

角色一致性评测平台更适合作为近期优先方向：数据和任务边界相对清晰，可以直接验证知识库、固定测试集、Bad Case 管理和版本回归机制。首版可以使用 20—50 条单轮、多轮、冲突、诱导和边界样本，批量比较模型或 Prompt 版本，并让编剧保留最终解释权。

游戏测试 Agent 更适合作为中期方向，从登录、领取、商店、背包、固定关卡和回归流程等可验证状态切入，输出轨迹、截图、日志摘要和复现步骤；暂不挑战开放式探索、复杂战斗策略或生产环境中的无限制操作。

对游戏 AI 产品经理而言，核心工作不是罗列模型和工具，而是把游戏生产或玩家体验中的问题拆成可验证任务，设计人机协作流程，建立离线评测与在线指标，并通过 Bad Case 与真实使用数据持续迭代。
