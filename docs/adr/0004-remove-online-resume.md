# ADR 0004：移除在线简历栏目

状态：已接受（2026-08-11）

日期：2026-08-11

## 背景

个人网站当前通过主导航、首页、About 和 Footer 提供 `/resume/` 在线简历入口，并维护在线简历正文、打印导出和三份待补充 PDF 的配置。正式简历后续改为通过招聘系统单独投递，网站的公开信息架构只需要承担项目、研究、随笔和个人介绍的证据展示。

## 决策

- 从主导航和移动菜单中移除“简历”，保留首页、项目、研究、随笔和关于。
- 删除 `/resume/` 页面、在线简历正文、打印导出入口和简历 PDF 配置。
- 删除首页、About、Footer 与兼容重定向中的简历入口，不新增下载简历或查看 CV 的替代行动。
- `/resume/` 不设置新重定向，访问时使用网站现有 404 行为。
- 保留全局打印样式文件，只移除其中仅服务于在线简历的选择器和规则。

## 与 ADR 0003 的关系

本决策取代 ADR 0003 中“主导航固定为首页、项目、研究、随笔、关于、简历”的部分。ADR 0003 对研究与随笔栏目拆分、内容集合和详情路由的其他决策继续有效。

## 影响

- 自动 sitemap、Pagefind 和静态构建不再包含在线简历页面。
- GitHub、搜索、主题切换、Header 高度和导航间距保持不变。
- 正式简历不再作为网站资源维护，由招聘流程单独提供。
